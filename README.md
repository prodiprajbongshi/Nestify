# Nestify – Store Landing Page Template

**Nestify – Store Template** is a modern, static landing page built with **Next js** ideal for showcasing furniture and lifestyle products.

## Demo Highlights
- Top header with brand greeting and contact info  
- Navigation links: Home, Products, Blogs, About, Contact  
- Featured products like “Glamour Gaze” and “Eldora TV Console” with pricing  
- Blog previews: e.g., Black Friday guide, Christmas party tips  
- Client logos section for social proof  
- Newsletter sign-up form for audience growth

## Why Choose It?
- Instantly deployable as a static site  
- Visually-appealing layout tailored for e-commerce  
- Lightweight and responsive  
- Easy to customize for your brand & products  
- Built to convert visitors into subscribers and shoppers

## Getting Started
1. Clone the repository  
2. Replace placeholders with your own images, product info, and blog content  
3. Update branding (logo, fonts, color scheme)  
4. Deploy using GitHub Pages, Vercel, Netlify, or similar platforms
